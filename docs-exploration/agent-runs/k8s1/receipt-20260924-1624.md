### Attempt Log

#### Attempt 1
- **Failure 1 (CLI syntax)**: Step 4 failed with `ERROR: (gcloud) Invalid choice: 'artifact'`. The command in the runbook was `gcloud artifact repositories` instead of `gcloud artifacts repositories`.
  - *Evidence*: `ERROR: (gcloud) Invalid choice: 'artifact'. Maybe you meant: gcloud artifacts repositories`
  - *Resolution*: Updated `deploy.sh` and `teardown.sh` to use `gcloud artifacts repositories`.
- **Failure 2 (Docker BuildKit permissions)**: Step 6 `make k8s-build` failed with `ERROR: failed to solve: failed to mount ...: operation not permitted` and legacy builder failed with `unshare: operation not permitted`. The executing container runner lacks host mount/unshare privileges required for local nested container image compilation.
  - *Evidence*: `ERROR: failed to solve: failed to read dockerfile: failed to mount /var/lib/docker/tmp/buildkit-mount...: [{Type:bind ...}]: operation not permitted`
  - *Resolution*: Configured `cloudbuild.yaml` and delegated image compilation directly to Google Cloud Build (`gcloud builds submit`) with BuildKit enabled (`DOCKER_BUILDKIT=1`) and machine type `E2_HIGHCPU_8`.

#### Attempt 2
- **Failure (Kustomize Image Name Mangling)**: Deploying manifests resulted in pods entering `InvalidImageName`. Kustomize's `newName` directive combined with `newTag: latest` appended an extra `:latest` tag when `newName` was populated with the full tag string (`.../agentenv-gateway:latest:latest`).
  - *Evidence*: `spec.containers{gateway}: Failed to apply default image tag ".../agentenv-gateway:latest:latest": invalid reference format`
  - *Resolution*: Updated `deploy.sh` image replacement step to parse image repository and tag separately and assign `newName` and `newTag` accurately. Re-applied manifests with `make k8s-apply`.

#### 2. Cloud Build Support for Container Runners in Step 6
Add Cloud Build option for environments where local Docker daemon cannot perform privileged BuildKit mounts:
```bash
gcloud builds submit \
  --project="${PROJECT_ID}" \
  --region="${REGION}" \
  --config=cloudbuild.yaml \
  --substitutions="_K8S_GATEWAY_IMAGE=${K8S_GATEWAY_IMAGE},_K8S_SCHEDULER_IMAGE=${K8S_SCHEDULER_IMAGE},_K8S_RUNTIME_IMAGE=${K8S_RUNTIME_IMAGE}" .
```

With:
