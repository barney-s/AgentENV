### Important Information for the Owner Before Running `deploy.sh`
1. **Automated Setup & Verification:** The `deploy.sh` script does not require interactive SSH commands. It automatically generates a local `vm_setup.sh` helper script, copies it to the remote VM via secure copy (`gcloud compute scp`), and runs the setup and verification steps completely unattended.
2. **First Boot Delay:** The VM startup script needs to install several large native packages via APT. `deploy.sh` actively polls the system's `google-startup-scripts.service` and waits for it to complete successfully before attempting compilation. This may take 1-2 minutes.
3. **Compilation Time:** Compiling AgentENV in release mode directly from source on the VM can take several minutes.
4. **Active Verification:** The script concludes by automatically fetching the generated API key and testing both the `/health` and `/sandboxes` endpoints of the bare-metal server directly on the VM, reporting the results back to your console.
